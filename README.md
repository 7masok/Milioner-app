# Склад / Milioner-app

Приложение учёта склада, закупок, заказов маркетплейсов и финансов.

Перед доработкой прочитайте **AGENTS.md**, затем **docs/SITE-PASSPORT.md**.
В паспорте находятся карта функций и файлов, правила поведения, цвета,
ограничения данных, проверки и порядок обновления самой инструкции.

На сайте: **Настройки → Для разработчиков → Открыть паспорт сайта**.
Текст берётся из того же Markdown-файла и доступен на сайте после входа.
Документация загружается только при открытии отдельной страницы `/developers`.

Среда: Node.js 22+, зависимости сервера устанавливаются командой
`npm ci --prefix railway`. Проверки: `npm test` из корня репозитория.
Запуск и переменные окружения описаны в `railway/README.md`.
