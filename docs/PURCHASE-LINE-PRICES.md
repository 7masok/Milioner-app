# Разные цены товаров в одной закупке — 29.10.2026

По решению владельца новая закупка и обычный редактор поставки используют цены по строкам вместо одной общей суммы с одинаковой ценой штуки. Это заменяет прежнюю схему общих сумм PURCHASE-06.

- У каждой строки: товар, целое положительное количество, выбор «Цена за штуку» / «Сумма за товар» и фактическая цена продавца. Оба режима можно сочетать в одной закупке.
- В режиме за штуку сумма строки равна цене × количеству; в режиме за товар сумма остаётся введённой, цена штуки вычисляется по количеству. Переключение при известном количестве сохраняет сумму строки.
- «Итого за товары» только для чтения, сумма строк. Сохранение и PDF заново считают суммы из строк, не доверяя запоздавшему экранному итогу. Цены из рекомендаций/истории остаются подсказками, в новые цены не подставляются.
- Новая строка без цены допускает нулевую стоимость, как прежде, в том числе для ещё не оплаченной корзины. Отрицательная/нечисловая/слишком большая цена и дробное количество блокируют сохранение всей закупки.
- Каждая строка сохраняет свои buyTotal и unitCost; все строки объединяет shipmentId. Итог shipmentPurchaseTotal одинаковый и равен сумме товаров. Доставка по-прежнему распределяется пропорционально количеству на этапе заказа/обычного редактирования; при подтверждении приёмки применяется прежний расчёт фактической доставки. Её способ не меняется этой задачей.
- Открытие обычного редактора сохраняет фактические суммы существующих товаров, в том числе при добавлении из корзины. Новые товары без фактической цены остаются незаполненными. Состав, ID партий, этапы, защита от устаревших данных и запрет редактирования уже списанных единиц сохраняются.
- Редактор исправления приёмки уже имеет цену за штуку: его общий итог теперь суммирует строки, не перезаписывая их цены после изменения количества/добавления товара.
- Сохранение заказа само по себе не увеличивает свободный остаток и не вводит товары в продажу. Существующие приёмка, продажа и FIFO сохраняются.

Проверки: purchase-line-prices.test.mjs — разные цены, оба режима, изменение количества, переключение режима, сохранение с запоздавшим общим итогом, редактирование, недопустимые значения без частичной записи, исправление приёмки, PDF. Старые проверки корзины, этапов, удаления и FIFO продолжают действовать.
