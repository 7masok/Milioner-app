# Единый период Отчётов · 29.10.2026

Нижние быстрые периоды удалены из рабочего интерфейса: остаётся только «Свой период», открывающий прежние поля дат. Верхние «Сегодня», «Вчера», «Неделя», «Месяц», «Год» и стрелки/свайпы графика задают даты нижней финансовой сводки и списка товаров для выбранного магазина либо «Все». Неделя — календарная с понедельника, месяц и год календарные; текущие диапазоны ограничены сегодняшней датой, не будущими днями. Исторический день передаётся точным from/to, не rolling N days. Сегодня/вчера сохраняют существующие специальные live-источники WB.

Явный нижний «Свой период» позволяет вручную переопределить даты финансовой сводки. Этот режим и введённые даты сохраняются существующими механизмами; возврат к верхнему календарному периоду или свайп снова синхронизирует нижние даты. Календарная диаграмма сохраняет свою выбранную календарную шкалу, произвольный ручной интервал не выдаётся за календарную неделю/месяц. Повторный выбор активной верхней кнопки должен вывести из ручного режима.

Обновление нижней сводки использует существующий renderer и его защиту от запоздалых ответов. Состояние магазина, остатки, цены и расчёт финансов не изменяются. Кнопки в детализации отдельных магазинов не удаляются.

Горизонтальный свайп работает также по нижней сетке финансовых карточек. Он переключает тот же календарный период, что и график, сохраняя положение страницы. Вертикальная прокрутка, короткое касание, отмена и несколько пальцев период не меняют. После свайпа подавляется случайный click карточки рекламы; обычное нажатие по ней открывает прежнюю детализацию.
