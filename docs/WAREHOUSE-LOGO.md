# Логотип склада

30.10.2026 владелец предоставил новый логотип — золотой доллар-персонаж. Существующий публичный app-icon.svg заменён: он содержит уменьшенную до 512×512 WebP-копию изображения с прозрачностью, без перерисовки и внешних запросов.

Manifest использует этот ресурс для PWA-иконки. URL иконки версионирован; purpose any оставляет безопасное вписывание браузеру. Обновление значка уже установленной PWA зависит от браузера/лаунчера. Серверный код и набор публичных маршрутов не изменены. Замена в шапке и экране входа в данный выпуск не включена.
