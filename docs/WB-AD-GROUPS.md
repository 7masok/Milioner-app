# Группы рекламы WB

Реклама → WB 1 / WB 2 → «＋ Группа рекламы». Владелец задаёт складское название товара и вручную отмечает его кампании. Группы не создаются по совпадению названий или нечётким привязкам. Один товар может иметь три и более кампаний в одной группе. Один ID кампании входит в одну группу в пределах кабинета. WB 1 и WB 2 разделены.

Группы и состав хранятся на сервере (migration 154), разворот — локально с ключом кабинета. Редактирование позволяет менять название и состав. Кампания, закреплённая за другой группой, недоступна для выбора. Пропавшие из текущего снимка кампании сохраняются в составе и явно помечаются в редакторе; их можно вручную убрать. «Расформировать» удаляет только группу и членство, не кампании, настройки, бюджеты или статистику. Версия записи защищает от потери одновременных изменений.

Список показывает группы, затем отдельные кампании без группы. Поиск учитывает название группы; текущие фильтры продолжают ограничивать дочерние кампании. Число показывает видимые / всего в группе, сводка группы относится к видимым кампаниям. Внутри — сравнение расхода, корзин и цены корзины за текущий выбранный период плюс прежние карточки с настройками и кнопкой «Запросы · корзины». Значения разных рекламных кампаний могут пересекаться по атрибуции, поэтому это сумма отчётных показателей, а не уникальные покупатели/заказы. При неполной истории групповой итог не выдаётся за подтверждённый.

Никаких вызовов WB при создании, редактировании, просмотре и расформировании групп. Нет смены ставок, запуска/паузы или автоматического тестирования. Настройка экспериментов — отдельная следующая задача владельца. API за авторизацией, проверкой Origin и запретом кэширования; SQL-запросы параметризованы. Изменение состава атомарно.
